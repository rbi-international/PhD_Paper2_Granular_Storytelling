# Provenance: test_prompts_160.csv

Generated by `src/6_ablations/make_test_prompts.py`. Do not edit by hand.

## Design

20 stems times 8 emotions (paired), giving 160 distinct (stem, emotion) rows.
Every emotion uses the SAME 20 stems, so accuracy differences between emotions
reflect the emotion conditioning rather than which stems that emotion drew.

Scored label distribution: Anger 40 (Disgust merged in), all other emotions 20,
N=160. This matches `hybrid_results.csv` exactly.

## Stem source

| Step | Value |
|---|---|
| Source file | `data/annotated/annotated_train.csv` |
| Excluded | every row appearing in `data/processed/final_train_ready.csv` |
| Held-out pool | 1407 rows |
| Teacher labels in pool | Neutral |
| After quality filter | 885 distinct 6-word stems |
| After neutrality filter | 686 stems verified neutral by the judge |
| Selected | 20, via `random.Random(20260826).sample(sorted(neutral_pool), 20)` |

Every held-out row carries the label `Neutral` because `02_balance_and_format.py`
balanced the training set by dropping surplus Neutral rows. That label applies to the
FULL story though, not to the six-word opening, so it is not sufficient on its own.
A long story can average to Neutral while opening on an air raid siren. The stems are
therefore scored a second time, in isolation, by the neutrality filter below.

Quality filter rejects encoding artefacts, URLs, reddit markup, escaped newlines,
stems under 12 words, stems with characters outside
`[A-Za-z0-9 ,'.-]`, and stems not starting with a capital.

## Neutrality filter

Applied by `src/6_ablations/filter_neutral_stems.py`, which scores every candidate
stem in isolation and writes `data/processed/neutral_stem_pool.csv` with the full
per-stem scores. The pool is filtered first and the selection drawn from it, rather
than selecting first and patching rejects, so the selection rule stays checkable.

A stem is accepted only if BOTH conditions hold:

1. `classify(stem) == "Neutral"`. The top sigmoid label maps to Neutral under
   `EMOTION_MAP`. This is the exact function that scores the generated stories, so
   the filter and the evaluator agree by construction.
2. `max P(any Plutchik-mapped emotion) < 0.20`. This catches the narrow case where
   Neutral wins at 0.31 while Fear sits at 0.29, which condition 1 alone would pass.

Judge: `SamLowe/roberta-base-go_emotions`, mapped to Plutchik-8, seed 20260826.

The paper can therefore state, literally and checkably, that the stems themselves
carry no target-emotion signal.

## Difference from the 47.50% headline run

That run used the fixed stem "The" for all 160 generations. These stems are varied.
The ablation numbers are therefore internally comparable to each other exactly, and
comparable to the 47.50% anchor in aggregate only. This needs a footnote in the
ablation table. Re-running the hybrid config on this manifest would make the two
directly stackable, which has not been done.
